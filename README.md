# 🏓 Anti-AI Table Tennis 3D

Браузерная 3D-игра в настольный теннис, написанная человеком с нуля.  
Никаких AI-генераторов кода, никаких сборщиков, никаких зависимостей.

---

## 🛡️ Почему "Anti-AI"?

Этот проект — часть серии **Anti-AI Shield**: коллекция бесплатных офлайн-приложений, созданных разработчиком без использования генеративного ИИ.

Каждая строчка кода написана вручную, протестирована и оптимизирована человеком. Цель — показать, что качественный, быстрый и красивый софт может создаваться без нейросетей.

> 🌐 Другие проекты серии: [ancf-hue.github.io](https://ancf-hue.github.io/)

---

## ✨ Особенности

- 🎯 **Полноценный 3D** — Three.js с тенями, освещением и шейдерами
- 🤖 **ИИ-соперник** — 3 уровня сложности (Легко / Нормально / Сложно)
- 📱 **Кроссплатформенность** — Desktop, iOS, Android
- 🔊 **Объёмный звук** через Web Audio API с HRTF
- 🎮 **3 способа управления** — мышь, клавиатура, сенсорные кнопки
- ⚡ **Авторежим энергосбережения** — для слабых устройств
- 📴 **100% офлайн** — работает без интернета
- 🆓 **Бесплатно навсегда** — без рекламы, без покупок

---

## 🕹️ Как играть

| Действие | Desktop | Mobile |
|----------|---------|--------|
| Движение ракетки | `← ↑ ↓ →` или мышь | Сенсорные кнопки ▲ ▼ ◀ ▶ |
| Подача | `Пробел` или клик | Тап по экрану |
| Пауза | `P` или `Esc` | Кнопка ⏸ |
| Звук | `M` | Кнопка ♫ |

**Правила:** Первый до 11 очков с разницей в 2.

---

## 🛠️ Технологии

- **[Three.js](https://threejs.org/) 0.163** — 3D-графика через ES Modules
- **Web Audio API** — процедурный звук и 3D-позиционирование
- **ES Modules + Import Maps** — без webpack, vite и других сборщиков
- **HTML5 Canvas + CSS3** — UI и пост-эффекты
- **Vanilla JavaScript** — ни одного фреймворка

> 💡 Весь код помещается в один `index.html` — откройте и изучайте.
